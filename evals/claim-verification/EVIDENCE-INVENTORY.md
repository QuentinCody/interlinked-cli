- Health considers only the newest 10,000 capture receipts / 4 MiB. `observed` means a producer write was observed; `unmeasured` and `not-observed` do not establish absence. File mtime below is not event time or completeness. The data index was absent at this snapshot.
- Bind a result to provider, session, actor, call ID, source/configuration identity, test selection and completion state. An activity summary or matching filename is insufficient linkage. Preserve unsupported, missing/truncated and failed-capture states.

## Cross-cutting capture gaps

1. **Claude failures:** both the legacy installer and adapter omit PostToolUseFailure registration while parsing that event if received. Failed tool results are therefore not uniformly available through hooks. Native transcript recovery can help only where those original records survive.
2. **Successful-tool matching differs by installer:** the legacy `src/lib/hook-installers-shared.ts` uses an empty PostToolUse matcher, but the current Claude adapter derives a mutating-tool matcher from the write-tool registry. The installed project settings were inspected: `Write|Edit|MultiEdit|NotebookEdit|Bash`. Thus this project's active hook registration does not cover every successful read/search tool. Native transcript/timeline capture is a separate recovery path. Historical settings must be checked separately; the legacy helper alone is not evidence of the installed contract.
3. **Evaluator projection:** `src/harness/jev/claim-evidence.ts` retains the last 25 tool entries, only the first 300 input characters and last 400 result characters. It does not preserve call IDs in its EvidenceEntry. Its native reader uses the last human-prompt boundary and tolerates malformed trailing JSON. These are evaluator losses in addition to provider/capture gaps.
4. **Command success:** the current tests feed can classify an outcome from shell exit code or provider success, without parsing the runner result. Pipelines can mask failures. Missing exit code is unknown; an agent claim or command input cannot substitute for a completion receipt.
5. **Native history:** native-claude is an explicit snapshot source, not automatic backup. The initial audit found one of eleven original session paths; archive recovery is the next work item, so those ten are not declared unrecoverable yet.
6. **Freshness:** source/config changes invalidate earlier verification independently of cached claim interpretation. A matching Git HEAD alone does not identify dirty files or the complete runtime/dependency closure.
