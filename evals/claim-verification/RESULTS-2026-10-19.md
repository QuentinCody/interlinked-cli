### Citation pipelines

Code retrieves exact returned-output windows and records offsets and source hashes. The Choice pipeline selects an excerpt or `none` in two opposite option orders. The independent-Noul pipeline judges each window, keeps those at or above 0.8, then separately judges whether the retained excerpts jointly support the complete claim. Neither variant generates source text. The thresholds are experimental acceptance rules, not calibrated guarantees.

On the same 30 development cases, comprising 16 supported and 14 unsupported cases:

| Pipeline | Supported cases accepted | Unsupported cases accepted | Supported cases missed |
| --- | ---: | ---: | ---: |
| Existing two-Noul baseline | 15 / 16 | 3 / 14 | 1 |
| Citation Choice | 2 / 16 | 0 / 14 | 14 |
| Independent citations, then complete-claim Noul | 7 / 16 | 0 / 14 | 9 |

The citation pipelines trade recall for fewer false endorsements. This is not evidence that they outperform the baseline overall. Retrieval, interpretation of fragments, strict selection thresholds, and final judgment all contribute to misses. A valid citation proves where text came from, not that it entails the claim. Low-confidence abstentions count as missed support here; API failures would be separately unmeasured.
