# Archived claim candidate queue

The original 699-row candidate queue remains in private local research storage. It
contains passages from historical native messages and is not included in this
repository. Credential redaction alone does not make those messages public data.

The queue was a pre-adjudication review aid: 369 inherited proposals and 330
initially unlabelled candidates. These rows were not promoted directly into ground
truth. Subsequent complete-message annotation produced 666 reference claim units
across 50 messages using independent model reviewers and reconciliation. These
are model references, not human labels or a population accuracy benchmark.

No labeling task is pending. See [the pilot README](README.md),
[the aggregate results](RESULTS-2026-10-19.md), and [the completed work status](NEXT.md)
for methods, measured outcomes, and interpretation limits. Reproducing historical
runs requires separately retained private datasets and frozen evidence; the
portable unit tests and authored fixtures do not require that corpus.
